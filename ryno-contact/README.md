# TerraHash Stack ROI Calculator & Marketing Web App  
**by HashGrid Networks & Ryno Holdings**

***

## OverviewThis repository contains all design assets, source code, and documentation for the **TerraHash Stack ROI Calculator & Feature Explorer** web application. This application is designed as a powerful sales, marketing, and educational tool for the exclusive partnership between HashGrid Networks (developer) and Ryno Holdings (sales partner) to promote and support the TerraHash Stack bitcoin mining platform.

***

## Features- **Professional Landing Page:**  
  Co-branded with HashGrid Networks and Ryno Holdings logos, modern blue-green color scheme, and technology/circuit board visual motifs.

- **Interactive ROI Calculator:**  
  Lets users input mining investment, electricity costs, number of ASICs, and current cooling method to visualize projected savings, profits, and ROI timeline using TerraHash Stack technology.

- **Feature Comparison Table:**  
  Clearly illustrates the advantages of TerraHash Stack vs. traditional bitcoin mining on key metrics: energy costs, cooling efficiency, hash rate, hardware lifespan, automation, and sustainability.

- **Tabbed Feature Explorer:**  
  Intuitive tabs explain each core innovation:  
    - Renewable Energy Integration  
    - Liquid Cooling Technology  
    - AI-Powered Automation  
    - Scalable Deployment Packages

- **Contact Form:**  
  Streamlined inquiry form for scheduling consultations, requests for proposals (RFPs), and follow-up from Ryno Holdings’ sales team.

- **Responsive & Accessible:**  
  Fully mobile-friendly and cross-browser tested. Includes alt text and sufficient color contrast for accessibility.

- **Marketing Integration:**  
  Promotional messaging in all sections highlighting Ryno Holdings as exclusive global sales partner.

## Usage Instructions1. **Clone or download the repository.**
2. Open `index.html` in any modern browser.
3. Use the ROI Calculator to visualize TerraHash Stack’s financial impact for your mining operation.
4. Click through the feature explorer for detailed info on each technology component.
5. Fill out the contact form to schedule a professional mining consultation with Ryno Holdings.

***

## Customization- Update company info, logo paths, and contact parameters in `/js/app.js` and `index.html`.
- Branding, color palette, and circuit-pattern backgrounds are fully adjustable in `/css/style.css`.
- Replace or update technology visuals and infographics in `/assets`.
